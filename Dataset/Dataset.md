# Dataset

This project uses the **Instacart Online Grocery Shopping Dataset**.

The raw dataset is not included in this repository because it exceeds GitHub's file size limits.

## Dataset Source

You can download the dataset from Kaggle:

https://www.kaggle.com/datasets/psparks/instacart-market-basket-analysis

## Required Files

After downloading the dataset, place the following files in the `Dataset` folder:

- aisles.csv
- departments.csv
- order_products__prior.csv
- order_products__train.csv
- orders.csv
- products.csv

These files are required to execute the SQL scripts and reproduce the analysis.
